## 语言选型说明

| 选项 | 优点 | 对本 demo 的代价 |
|---|---|---|
| TypeScript / Node | 前后端同语言；coding-standards 示例偏 TS | 后台样板与类型胶水偏多 |
| **Python** | 邮件/AI SDK 成熟；状态机与规则表达简洁；S0 可用标准库验收 | 工作台若要重 UI 需另选前端 |

结论：本项目是精致 demo、后台不宜过重，**选 Python**。S0 不依赖 PyPI；S1 引入 FastAPI 等。工作台用轻量服务端渲染或简单静态页即可。
