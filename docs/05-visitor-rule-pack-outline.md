## 核心待证主题（非穷尽清单）

来自官方“genuine visitor”要求，系统用要求状态跟踪，**不用** Student 固定资金规则：

1. 护照/旅行证件有效  
2. 访问目的为允许活动，且材料与陈述一致  
3. 行程结束将离开英国的合理依据  
4. 能负担本人（及适用依赖人）停留费用与回程/续程费用  
5. 个人在本国情况（工作/学习/自雇等）与陈述一致  
6. 若有赞助人：支持内容、关系、赞助人能力与（如适用）在英合法身份  
7. 非英/威译文：完整译文 + 译者确认信息（姓名、签名、日期、联系方式）

## 官方明确“不宜作为主要证据”的材料（勿鼓励堆砌）

酒店/机票预订（过境除外）、信用卡账单、驾照、旅游保险、赞助人市政税/水电账单、私人照片、名片、一年以上银行函等——见访客材料指引第 13 节。

## 与 Student / Skilled Worker 的隔离

- 禁止套用 CAS/CoS 或 Student 资金期间公式  
- 客户说“工作签”只产生候选路线，不自动建 Skilled Worker 清单
